ПЛАЗМА — постоянная рабочая папка сайта

Эту папку больше не нужно заменять новой папкой на каждом шаге.
Сохрани её под названием PLAZMA_SITE и продолжай работать только в ней.

КАК ОТКРЫТЬ САЙТ
1. Дважды нажми OPEN_SITE.bat.
2. OPEN_SITE.bat сначала пересоберёт public из актуальных файлов src, затем откроет public\index.html.

Важно: для корректного просмотра после изменений запускай сайт именно через OPEN_SITE.bat, а не открывай старый public\index.html вручную до пересборки.

ШРИФТЫ
Gabriela, Izax SHA и Shafarik уже находятся внутри сайта:
public\assets\fonts

Устанавливать их в Windows или запускать отдельный установщик не нужно.
Они будут загружаться самим сайтом и отображаться на других компьютерах и телефонах.

КАК БУДУТ РАБОТАТЬ СЛЕДУЮЩИЕ ОБНОВЛЕНИЯ
Все изменения вносятся в исходники проекта и затем собираются через build.py.
Папку со шрифтами без необходимости не трогаем.

ВАЖНО
- Не удаляй папку public\assets\fonts.
- Не возвращайся к старым папкам step_1, step_2 и т. д.
- Рабочая папка теперь одна: PLAZMA_SITE.
- Для просмотра актуальной версии используй OPEN_SITE.bat.
